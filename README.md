# TCC: Análise Comparativa de Arquiteturas e Paradigmas em Jogos
## Um estudo de caso prático com o jogo Tetris.
### 📄 Sobre o Projeto
Este repositório contém o código-fonte e os materiais do meu Trabalho de Conclusão de Curso. O projeto consiste em uma investigação prática sobre como as escolhas de arquitetura de software e tecnologia de desenvolvimento impactam o ciclo de vida de um jogo.

Este projeto consiste na implementação do jogo Tetris em quatro versões diferentes com quatro ferramentas diferentes, sendo elas:
1. Godot
2. LibGDX em java
3. Raylib em C++
4. Pygame em Python

Todas as versões são iguais entre si, contendo as mesmas estruturas, como uma grade 10x20, movimentação básica, sistema de rotação simplificado, colisão, verificação e remoção de linha, algoritmo 7-Bag, marcação da peça e sistema de pontuação.
